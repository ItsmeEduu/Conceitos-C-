# 🚀 Conceitos C++

Uma coleção de algoritmos práticos em **C++** desenvolvidos para consolidar conceitos fundamentais de lógica de programação, matemática e manipulação de fluxos de dados.

---

### 📌 Programas Incluídos

* **`calculador de medias.cpp`**: Processa entradas numéricas, calcula médias aritméticas e valida o status de aprovação.
* **`leitor de coordenada.cpp`**: Identifica e localiza a posição exata de pontos dentro de um plano cartesiano (X, Y).
* **`sistema de calculo de salario.cpp`**: Automatiza a folha de pagamento calculando salários brutos e líquidos com base em regras de negócio.

---

### 🛠️ Tecnologias e Conceitos Aplicados

* **C++ Moderno**: Uso de fluxos de entrada/saída (`cin`/`cout`) e manipulação de variáveis de precisão flutuante (`double`/`float`).
* **Lógica Estruturada**: Implementação de estruturas condicionais encadeadas (`if / else`) e operadores aritméticos.
* **Boas Práticas**: Organização de arquivos clara e versionamento de código focado em legibilidade.

---

### 🚀 Como Executar

```bash
# 1. Clone o repositório
git clone https://github.com

# 2. Compile o arquivo desejado
g++ "calculador de medias.cpp" -o calculador_medias

# 3. Execute o programa
./calculador_medias
```
